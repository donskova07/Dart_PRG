**5. Ответы на вопросы**

1. Абстрактный класс — это «чертёж» для других классов: он задаёт общую структуру (поля, методы) и может содержать как реализацию, так и только объявления методов (без тела). Его нельзя создать как объект напрямую.
Нельзя написать Character(), потому что это абстрактная сущность
2. super вызывает конструктор родительского класса, чтобы инициализировать унаследованные поля.
Если его убрать, Dart попытается автоматически вызвать конструктор родителя без параметров. Если у родителя нет конструктора без параметров код не скомпилируется 
3. Аннотация @override в обоих случаях просто говорит компилятору: "Я намеренно переопределяю метод родителя".
Разница в том, что attack(), скорее всего, в родителе абстрактный (не имеет тела/кода), поэтому в Warrior мы пишем его реализацию с нуля. А takeDamage() в родителе уже имеет готовый код (например, отнимает здоровье), но Warrior переопределяет его, чтобы изменить поведение (например, учесть броню и получить меньше урона).

4. Эта концепция называется Полиморфизм 
Во Flutter видели это повсюду, где используется тип Widget. Например, в свойстве children у Column

5. Нижнее подчёркивание в Dart означает приватность на уровне библиотеки (файла). Переменная _random доступна только внутри файла, где написан класс Character, и скрыта от других файлов проекта
