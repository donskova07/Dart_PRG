#### Лабораторная работа №7. Углублённое ООП в Dart — RPG-битва
**Цель работы:** Изучить наследование, абстрактные классы, переопределение
методов и полиморфизм. Написать консольную RPG-битву где эти концепции
возникают естественно из задачи.
Необходимые инструменты:
- Dart SDK 3.0+
- VS Code с расширением Dart
- Git

**2. Информация**
*Донскова Ульяна ИСП-242*

**3. Как запустить**
- Запустить vs code
- зайти в файл main.dart
- нажать на кнопку run

5. ОТВЕТЫ

1. Абстрактный класс — это «чертёж» для других классов: он задаёт общую структуру (поля, методы) и может содержать как реализацию, так и только объявления методов (без тела). Его нельзя создать как объект напрямую.
